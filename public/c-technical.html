About

I'm Varun Malhotra, a Data Scientist working on generative AI and LLM engineering at Michelin in Pune, India. My work sits across three layers of the same problem: agent architecture — deciding what an LLM system is allowed to do and when it should stop and ask; evaluation — building the benchmarks that prove a system works before a user finds out it doesn't; and guardrails — the read-only boundaries and human-in-the-loop gates that keep an autonomous system honest in production.

On Talk to Data I own the agent architecture, LLMOps, security and frontend workstreams — I architect, build, and engineer the system end to end.
